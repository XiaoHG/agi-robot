# Open Questions

These questions must be answered before architecture work can be considered stable:

- What is the intended user and primary entertainment scenario?
- Which hardware platform and operating system will run the robot?
- Which actuators and sensors are required for the first prototype?
- Is the robot autonomous, remotely controlled, or hybrid?
- What are the safety, thermal, battery, and physical movement constraints?
- Which languages, runtimes, and external services are acceptable?
- What is the target prototype date and definition of done?
